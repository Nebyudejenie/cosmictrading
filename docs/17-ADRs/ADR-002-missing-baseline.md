# ADR-002: Requirements come only from the master prompt; the missing baseline is a blocker
- **Status:** Accepted · **Date:** 2026-10-10
- **Context:** The master prompt depends on `cosmictrading.md` / V4–V5 Sections 0–1803, which do not exist. The owner instructed that the master prompt be treated as the product vision.
- **Decision:** derive requirements only from the 1,468 lines that exist; record capabilities the prompt merely names (World Brain, Search Fabric, knowledge graph, global coverage) as a capability map (MIS-03), BLOCKED on B-01 and DEFERRED by scope. Where V6 says it "supplies binding detail where earlier sections were general", V6 text governs.
- **Consequences:** no invented requirements; scope is honest; when the baseline arrives, new requirement IDs are added without renumbering existing ones.
