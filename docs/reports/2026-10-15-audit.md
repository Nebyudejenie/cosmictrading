No HFM proposal has been made yet, so nothing was approved on these terms.

## Security risks

This repository is public, so this section names no credential and no place where one is kept. The owner was given the details directly.

1. **Credential housekeeping:** owner steps, given to the owner directly. The AI gateway refuses models without `:free` and checks for $0 prices whatever a key allows.
2. **The bridge's credentials live on the owner's everyday Windows PC** (restricted by NTFS permissions; `bridge/README.md`). Whoever controls that PC can send fake reports for the demo account. The server refuses to send commands to a non-demo account. Production should use the dedicated Windows VM (B-10).
