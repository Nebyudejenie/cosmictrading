How to win on gold: the levers that matter

  1. Pay less for each trade

    {% if g.measured_fee %}Your {{ g.measured_fee.venue }} trades show a commission of {{ "%.2f"|format(g.measured_fee.bps) }} bps a side over {{ g.measured_fee.fills }} fill(s).{% if g.fee_advice %} {{ g.fee_advice }}{% endif %} {% endif %}{% if d and d.trades %}Costs took {{ "%.2f"|format(d.cost_r / d.trades) }} R a trade on hourly bars.{% endif %} Check the real commission in MT5 (History → Commission) and set it under Risk policy → Fee per venue: until then a 0.6 % fee is assumed. Fewer, longer trades (daily bars) pay costs less often relative to the move they catch.

  2. Trade only what earned it

    {% if g.competition %}In the rule competition, gold has {{ g.competition|selectattr("tier", "equalto", "QUALIFIED")|list|length }} qualified and {{ g.competition|selectattr("tier", "equalto", "PROMISING")|list|length }} promising rule(s) of {{ g.competition|length }} tested{% if g.competition_at %} ({{ g.competition_at.strftime("%d %b") }}){% endif %}.{% else %}The rule competition has not covered gold yet.{% endif %} A rule must make money on prices it never saw, then forward from {{ forward_from.strftime("%d %b %Y") }}, before your auto-trader uses it.

  3. Size it to your money

    {% if g.one_lot_risk is not none %}One ounce risks about {{ g.one_lot_risk|dec(2) }} at the stop: at Normal (1 %) that needs about {{ g.minimum.get("NORMAL", 0)|dec(0) }} of money.{% endif %} A trade too big for your limit is skipped, never forced.

  4. Beat the simple benchmark

    {% if longest %}Buying {{ "%.0f"|format(longest.acc.invested / longest.acc.months) }} of gold every month for {{ longest.years }} year(s) would have turned {{ "{:,.0f}".format(longest.acc.invested) }} into {{ "{:,.0f}".format(longest.acc.value) }} ({{ pct(longest.acc.gain_pct) }}).{% endif %} A trading rule is only worth running if it beats that after costs. So far, none has on gold.

  5. Protect the money

    Your auto-trader stops for the day after three losing trades and for good after ten. Demo money only, until a rule has a proven record and you decide otherwise.
